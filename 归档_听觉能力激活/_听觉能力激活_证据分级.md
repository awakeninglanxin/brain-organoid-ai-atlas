# 听觉能力激活 · 同类研究证据分级

> 2026-11-06 检索与核对。起点是朱念麟「天耳机」的硬件描述（8 盏灯对应 8 级音量、每级递减 50%，第 7 盏仍听清即判「天耳打开」），追问：全网有没有**同一件事**的其他做法，以及科学上站得住多少。
>
> 归档原始页面 25 份，见同目录 `_归档清单.md`。失败项如实记录，不伪造。

## 0. 一句话结论

**「把阈值一级一级往下压」这件事，在听力学里不但有同类做法，而且有名字**（自适应心理物理法、听觉知觉学习、传出系统增益训练）。但它能压下去的是**「在噪声里能用多弱的信号」**，压不动**「耳蜗能听见多弱的声音」**——后者由毛细胞和耳蜗内噪声决定，训练不改变。

因此朱念麟的「天耳打开」如果只写「听得见常人听不见」，是**不可检验的**；写成「在指定噪声条件下，可辨阈限比训练前下降 X dB，且伴随 CSOAE 增益上升」，才是一个能被做掉或被证实的命题。

## 1. 先算清一个数：每级 −50% 到底是几 dB

「递减 50%」若指**声压/振幅减半**，换算固定：

```
ΔL = 20·log10(0.5) = −6.02 dB
第 n 级电平 = L0 − 6.02·(n−1) dB
```

八级走完，累计衰减 `6.02 × 7 = 42.1 dB`。若起点是 20 dB SPL：

| 级 | 换算 dB (SPL) | 与正常听阈（1 kHz ≈ 0 dB SPL）的关系 |
|---|---|---|
| 1 | 20.0 | 阈上，清楚可闻 |
| 2 | 14.0 | 阈上 |
| 3 | 8.0 | 接近阈限 |
| 4 | 1.9 | **已在阈限附近** |
| 5 | −4.1 | 低于正常听阈 |
| 6 | −10.1 | 物理不可闻 |
| 7 | −16.1 | 物理不可闻 |
| 8 | −22.1 | 物理不可闻 |

**这是一个硬矛盾**：如果「第 7 盏仍听清」是字面意思，等于宣称听阈比正常人低 16 dB。这不可能，因为耳蜗自身有内部噪声基底（热噪声与自发活动），正常听阈已经贴着这个基底。

三种能让描述自洽的解释，必须由原描述者选一个：

| 解释 | 换算 | 结果 | 需要补充的说明 |
|---|---|---|---|
| A. 20 dB 是**声压级起点** | 每级 −6.02 dB | 第 4 级即到阈限，第 7 级不可能 | 与「第 7 盏仍听清」直接冲突 |
| B. 每级减半指**功率**减半 | 每级 −3.01 dB | 20→17→14→11→8→5→2→−1，第 7 级 2 dB，第 8 级 −1 dB | 第 7 级恰在青年人听阈边缘，勉强可能；须说明是功率 |
| C. 20 dB 是**设备音量档位**，非校准 SPL | 无法换算 | 只说明相对衰减，绝对电平未知 | 必须给出换能器灵敏度与耦合方式，否则无法与听阈比较 |

**顺带一个必须问清的物理项**：天耳机是气导耳机还是骨导？气导要看耳罩/耳塞的耦合腔容积与漏气，骨导要看颅骨振动传递与乳突接触压力——两者在同一「档位数字」下对应的 SPL 可以差十几 dB。这一点不交代，「第几盏」没有物理意义。

## 2. 三类「同类」，证据强度差三个数量级

### A. 硬件化听觉刺激方案（商业产品，结构最像）

| 方案 | 硬件与做法 | 与天耳机的相似点 | 证据状态 |
|---|---|---|---|
| **Tomatis 电子耳** | 滤波 + 电子门控（gating）+ 气导与骨导同时给声 + 左右耳时间延迟；强度与频段按阶段切换 | 都是「硬件 + 分级 + 逐级加难」；都用骨导/气导双路 | 系统综述结论不一致；多数研究样本小、缺盲法 |
| **Berard AIT** | 滤波削掉个体「超敏」频段 + 随机调制高低频与强度；10 天 × 2 次 × 30 min = 10 h | 「按频段/强度逐级暴露」 | 6 项 RCT 系统综述：**证据不足**；多个专业学会列为实验性 |
| **Samonas** | 滤波音乐 + 空间化，Tomatis 派生 | 同上 | 证据更薄 |
| **Fast ForWord** | 计算机自适应，逐级压缩时长/频率过渡 | 自适应难度阶梯 | 对语言障碍有争议，对听力阈值无效 |

### B. 实验室听觉知觉学习（证据最硬）

| 研究 | 设计 | 关键结果 |
|---|---|---|
| Wright 综述口径（Northwestern） | 综述 | 可训练：频率/时长/位置/顺序辨别、**噪声中检测更弱的声音、检测更小的强度波动**；且需达到「单日学习阈值」，练够才留存 |
| Amitay 2013（PMID 24296314） | 综述 | 学习是复合效应：从相位锁定的噪声降低，到工作记忆容量，还含**非感觉因素（反应偏向、决策效率）** |
| Ferguson 2014 RCT（PMID 24752284，Ear Hear 35(4):e110-21） | 50–74 岁轻度感音神经性听损，8–12 周家庭训练，交叉设计 | 音素辨别**稳健进步，基线最差者进步最大**；自评听障、分心注意、工作记忆改善并保持 4 周；**噪声中言语识别没有一致改善** |
| Wang 2020（PMC7653913） | 精细辨别训练（ILD / F0） | 训练可「垂直迁移」到噪声中言语识别，支持训练共享底层过程 |

### C. 传统功法（无硬件、无阈值、无对照）

「天耳心听法」「天耳三密法」这类功法，做法是**极静环境 + 长时间注意内收 + 捕捉「听觉意象」**，判断标准是主观的「声音由模糊变清楚、音量变大」。它更接近**听觉注意与想象训练**，没有任何可测阈值、没有对照、也没有客观伴随指标。归类为 D 级（见 §5）。

值得单列一句：佛教《楞严经》观世音**耳根圆通**「初于闻中，入流亡所」，把「注意力从声尘收回」写成修行次第——这是**教理**，不是实验报告；但它在方法学上指向的东西（注意对听觉加工的调制）恰好是现代研究里真实存在的变量。

## 3. 真正被证明「能练」的，是三层；不能练的，只有一层

### 3.1 中枢与决策层：能练，效应中等

- 能练的具体项：频率/时长/方位/顺序辨别、**噪声中检测更弱信号**、**检测更小的强度波动**（Wright 综述口径）。
- 迁移有限：Ferguson 2014 的 RCT 里，音素辨别大幅进步，但**噪声中言语识别无一致改善**；真正改善的是自评听障、分心注意、工作记忆。
- 这提示一件事：训练改善的很大一部分不是「耳朵变灵」，而是「**更会用**现有信号」——决策效率、注意分配、反应标准。

### 3.2 传出层（MOCB）：能练，但效应小、个体差异大、还有反证

这是与「天耳机」结构最贴近、也最值得写进文档的一层。耳蜗外毛细胞的放大增益由**内侧橄榄耳蜗束（MOCB）**下行控制，可用**对侧声抑制的耳声发射（CSOAE）**无创读出。

| 研究 | 样本与设计 | 关键数值 |
|---|---|---|
| PMC6670751（2019） | 16 名正常听力女性（22±4 岁），5 天辅音-元音噪声辨别训练，逐日测 MOCB | 8/16 为学习者；学习斜率与首日对侧抑制相关 **r=0.74（幅度）/ r=0.79（输入输出）**；初始成绩与学习量 **r=−0.82**；改善主要发生在**前 3 天（Δ=9%）** |
| Gowri & Maruthy 2026（Egypt J Otolaryngol，DOI 10.1186/s43163-026-01135-y） | 26 人（13 训练 / 13 看视频对照），2 周 12 次言语噪声训练 | 训练组 CSOAE 与 SNR-50 均显著改善、对照组无；CSOAE 变化预测 SNR-50 变化 **β=−0.712，R²=0.507**；基线 CSOAE 越低，增益越大 **r=−0.660** |
| Bidelman 2017（Hear Res 344:275-283） | 横断比较音乐家与非音乐家 | 音乐家双侧 MOC 增益更强，且与**受训年限**相关 |
| Auckland 2020 硕士论文（反证） | 训练前后测 TEOAE/DPOAE 对侧抑制 | 词识别有进步，但**耳声发射指标无显著变化**，作者归因为「策略改变而非传出改变」 |

**结论口径**：MOCB 可塑性是**存在的、可测的**，但它是「增益旋钮」，不是「换更灵敏的麦克风」。效应量小（R²≈0.5 已是较好结果）、个体差异极大、且至少有一项独立研究未复现。

### 3.3 皮层重映射：能练，但要感觉剥夺或长期训练

Norman / Thaler 2024（*Cerebral Cortex* 34(6):bhae239，PMC11186672）：12 名盲人 + 14 名视力正常者，10 周点击式回声定位训练。结果：

- 两组**初级视皮层 V1 对回声的激活都上升**——与「感觉皮层严格按模态组织」的经典观点冲突；
- 右半球 A1 对一般声音的激活上升，伴灰质密度增加；
- 行为上（BPS 报道，二手）：虚拟迷宫用时视力正常组 104.1→40.9 s，盲人组 137→57.2 s。

这说明成人脑**能给新输入腾出皮层地盘**，但代价是十周密集训练 + 特定任务；它证明的是「**新通道**」，不是「**更低的阈限**」。

### 3.4 不能练的一层：耳蜗绝对听阈

两句直接的文献口径：

- 「听觉训练不改善外周听觉敏感性，即**纯音阈不变**」（PLOS Glob Public Health 2020，引 Bamford）
- 「耳蜗的基本生物物理属性**不太可能被训练改变**；能被调制的是外毛细胞功能，且由橄榄耳蜗束调制」（PMC4426073 综述）

也就是说：**毛细胞死了就是死了，阈值贴着耳蜗内部噪声，训练压不下去。** 这一条是「天耳」类主张必须绕过的硬墙。

## 4. 「听常人听不见」的四条物理通道（都有真实机制，都有硬边界）

| 通道 | 机制 | 关键数值 | 边界 |
|---|---|---|---|
| **骨导超声 BCU** | 24 kHz 以上气导不可闻，经颅骨振动仍可感知；机制为耳蜗底回内毛细胞直接受激或传输路径非线性解调 | 30 kHz 纯音可辨；文献报道高达 120 kHz；Fujimoto 2005 显示 30 kHz 载波调幅下频率差阈接近气导 0.25–4 kHz 水平 | 动态范围明显窄于气导；掩蔽 10–14 kHz 气导信号；语音可懂但音质差 |
| **超音效应 hypersonic** | >20 kHz 不可闻高频成分影响脑活动 | Oohashi 2000（J Neurophysiol 83:3548-3558）：22 kHz 以上成分使枕区 alpha 功率↑、脑干与左丘脑 rCBF↑、主观更愉悦；2014 研究：>32 kHz 为正向、<32 kHz 为负向 | **只在全身暴露时出现，仅耳机不给**；NHK 实验室复现失败；听觉机制仍争议 |
| **微波听觉（Frey 效应）** | 脉冲微波使组织瞬时热弹性膨胀，产生压力波经颅骨传至耳蜗 | 1.245 GHz 峰值功率密度阈值 <80 mW/cm²；脉冲 10–70 μs、重复率 50 Hz；可辨简单码 | 语音可懂度极差；MEDUSA 项目未成；「声到颅」的传言远超实际能力 |
| **30 kHz 骨导超声抑制耳鸣** | 底回宽频激活，覆盖多数耳鸣主调频率 | 21 名耳鸣者中 19 名（90.5%）出现残余抑制，时长显著长于 4 kHz 声 | 属症状缓解，不是听力提升 |

四条合起来说明：**「听到常人听不到的东西」在物理上确实可能**，但每一条都有明确的频率、剂量、耦合方式与可测指标——没有一条是靠「第几盏灯」定义的。

## 5. 天耳机与听力学对应物逐项对照

| 维度 | 朱念麟「天耳机」 | 听力学对应物 | 差距 |
|---|---|---|---|
| 刺激 | 8 盏灯对应 8 级音量，逐级递减 50% | 自适应心理物理阶梯（staircase / Békésy 追踪） | 结构同构；但**没有给出起始绝对电平、换能器类型、耦合方式** |
| 判据 | 「第 7 盏仍听清」＝天耳打开 | 阈值定义需指定：频率、信号类型、判定规则、试次数、置信区间 | 「听清」不可量化，无法算阈限 |
| 升级规则 | 逐盏升级 | 达到判据才升难度（如 Gowri 2026：10 dB SNR 达 80% 才降到 9 dB） | 规则同构，但缺**量化放行标准** |
| 客观伴随 | 无 | CSOAE / TEOAE / DPOAE 输入输出函数 / ABR wave V / MMN | 完全缺失，无法排除报告偏向 |
| 对照 | 无 | 假刺激、随机档位、等待组 | 完全缺失 |
| 时间结构 | 未说明单次时长与总次数 | 学习需达「单日阈值」；8–12 次为常见窗口 | 无法判断是否够量 |
| 证据等级 | **D 级**（个人记述 + 无对照） | A/B 级（RCT、预注册、可复现） | 差 2 个数量级 |

**一句话**：结构上它是一台**没做校准、没有对照、没有客观读出的自适应阈限训练器**。这不是「伪科学」，而是「**没做完的实验设备**」——缺的正是让它变成科学的那几样东西。

## 6. 要把它变成可检验命题：三级判据 + 最小实验

### 6.1 三级判据

| 级别 | 判据 | 通过意味着 |
|---|---|---|
| 一级（行为） | 指定条件下可辨阈限下降 ≥ 3 dB，且超过重测信度（test–retest） | 确实「更会用」信号 |
| 二级（客观） | CSOAE 抑制量上升，或 DPOAE 输入输出函数斜率改变，或 ABR wave V 潜伏期缩短 | 传出/外周增益真的变了 |
| 三级（盲法） | 假刺激组与随机档位组无同等改善 | 排除期望、练习、报告偏向 |

三级全过 → 支持「传出增益训练」；只过一级 → 归为决策/注意训练；一级都不过 → 主张不成立。

### 6.2 最小实验（可直接照做）

- **分组**：3 臂 —— ①真实 8 级递减；②随机档位（同总时长、同刺激数，但不单调递减）；③sham（同操作、无声或极低不可辨声）。每臂 16 人（双侧 α=0.05、power=0.8、σ=3 dB、Δ=3 dB 时的最小样本量）。
- **主要终点**：噪声中言语接收阈（SNR-50）变化。
- **次要终点**：安静纯音阈（**预期不变**，作为阴性对照）、CSOAE 抑制量、DPOAE I/O 函数、ABR wave V、MMN。
- **盲法**：受试者不知组别；档位由程序随机；测试者与操作者分离；测试与分析预注册。
- **判据**：ΔSNR-50 ≥ 3 dB 且 CSOAE 同向变化 → 二级通过；仅主观「更清楚」而无客观变化 → 记为报告偏向。

这个设计与 `BBB` 第 11 章的 hPGO 差分 DOE 是同一套逻辑：**把「意念/训练」变成自变量，其余物理量全部锁死。**

## 7. 判断与待办

**判断**：

1. 「激活耳朵听力」在**中枢与传出层**确有科学对应物，且有可测指标；在**耳蜗绝对阈**层面不成立。
2. 天耳机的「8 级递减」是合理的方法学骨架，但缺校准、缺客观读出、缺对照，因此现有描述**不可证伪**。
3. 「天耳打开」若指「听到常人听不到的声音」，必须落到 §4 四条物理通道之一，并给出频率与剂量；否则无法与「更会听」区分。
4. 传统功法与商业听觉刺激方案（Tomatis/AIT）**证据等级相同地弱**，不能互相担保。

**待办**：

- 天耳机的原始档位数值（起始 dB、每级是声压还是功率、气导或骨导）——现有材料未给，须回原书或问当事人。
- Gowri 2026 与 Auckland 2020 结论冲突，需第三项独立复现；目前只能写「存在争议的可塑性」。
- 维基三条（AIT 机构立场、微波听觉、超声听觉）本轮全部 502，未存全文；AIT 的机构立场改用 PMC2082994 的系统综述结论表述。
